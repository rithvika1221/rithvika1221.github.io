# rithvika1221.github.io

Personal website of Rithvika Devisetti, served at https://rithvika1221.github.io
(mirror of https://rithvika.dev).

The whole site is one self-contained file: `index.html`.

## Updating
- **Edit here:** change `index.html` and commit to `main`; GitHub Pages republishes in a minute or two.
- **Re-copy from rithvika.dev:** Actions tab → "Sync site from rithvika.dev" → Run workflow.
  This overwrites `index.html` with the live rithvika.dev page (the footer will say "hosted on Vercel" again).
